# BUILD100

> **Build your first 100 clients.**

A personal business-learning operating system designed for focused daily execution and client acquisition.

## Overview

BUILD100 combines a clean, Apple-grade interface with the visual architecture of modern learning platforms (Skool reference) tailored as a single-user founder operating system.

### Core Modules

1. **Dashboard**: Daily operator greeting, priority tracking, today's live session countdown, daily check-in (applied vs studied), reality check status callout, and side-by-side **Execution vs Learning** metrics.
2. **Classroom**: Structured curriculum tracks for **Sales**, **Content**, and **Offer**, including the Cold Calling Module and interactive lesson modals.
3. **Calendar**: Monthly simulated live training schedule (Offer with Emad, Sales with Saad, Content with Shafaq, Deep Dives).
4. **Business**: 100-client acquisition engine, lead and revenue metrics, Instagram repost distribution tracker, and daily build log journal.
5. **Leaderboard**: Single-user "Jason vs Jason" operating benchmarks, Level 1–9 progression ladder, XP capability scoring (Execution, Application, Business), and personal best records.
6. **About**: Program overview, 3 foundational pillars, operating philosophy (*"The objective is not to finish the classroom. The objective is to become the kind of operator who can build a real business"*), and mentor roster.

## Tech Stack

- **Frontend**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla CSS Design System (Custom CSS variables, Apple-level minimal aesthetics)
- **Icons**: Lucide React + custom SVGs

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
